# ODRL-DPV

Policies of [SDS2026-DPV-ODRL-mapping](https://github.com/besteves4/SDS2026-DPV-ODRL-mapping), which accompanies the paper *Bridging DPV and ODRL for Legally-Oriented Usage Control in Data Spaces* (SDS 2026).
Copied from [odrl-force/odrl-validator](https://github.com/odrl-force/odrl-validator), commit `e329d2f` (`data/profiles/odrl-dpv`).

All of them use the [DPV-ODRL profile](https://w3id.org/dpv/mappings/odrl). We checked that the actions and left operands that they use are defined in the profile.

The expected results are in [expected.json](expected.json).
